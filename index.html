Daily Email Summary

This is a personal, non-commercial automation tool. It runs on a schedule, reads a user's own Gmail inbox (or inboxes) using read-only access, and generates a short AI-written summary of recent emails, which is then delivered to that same user as a push notification.

It is built and used by a single individual for their own personal email management. It is not distributed, sold, or offered as a service to the public.

See the Privacy Policy for details on how data is accessed and handled.
