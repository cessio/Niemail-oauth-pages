Privacy Policy

Last updated: 2026

This tool ("Daily Email Summary") is a personal automation script built and used by a single individual. This policy describes how it handles data accessed through Google's Gmail API.

What data is accessed

The tool requests read-only access to Gmail (gmail.readonly scope). It reads email metadata and message previews (sender, subject, and a short snippet) from the last 24 hours, for the sole purpose of generating a personal daily summary.

How the data is used

Email content is sent to Google's Gemini API to generate a short text summary. That summary is then delivered as a push notification to the same individual who owns the inbox. No email content is stored permanently — it is used only in memory for the duration of each scheduled run and then discarded.

What is not done with the data

Email data is never sold, shared with third parties, used for advertising, or used for any purpose beyond generating the daily summary described above.

Who has access

This tool is used only by the individual(s) who explicitly authorize it with their own Google account. It is not offered publicly and is not intended for use by anyone other than its owner/operator.

Contact

Questions about this tool can be directed to the developer contact email listed on the associated Google Cloud project.
